Project Implicit's public Race IAT dataset: codebooks and notes
================================================================
What these are: the documentation Project Implicit publishes with each year's Race IAT data (the data
files themselves, hundreds of MB, are not kept here).  Each codebook lists every variable recorded that
year: the IAT scores and statistics, and each questionnaire item's wording and answer codes.

Where they come from: the Files section of https://osf.io/52qxl/ (Project Implicit's Race IAT public
data), whose storage is also served as one zip at
https://files.osf.io/v1/resources/gwofk/providers/osfstorage/?zip= ; every file here was downloaded from
that Files section, 2026-10-30/31.  The series is described in Xu, Nosek & Greenwald 2014
(references/papers.bib, xu2014raceiatdata).  Licence: as stated on the OSF project page (see NOTICE).

How this repository uses them:
  Race_IAT.public.2025.codebook.csv   tools/codebook_to_questionnaires.py -> offline/studies/race/codebook_items.js
                                      (kept as plain text, not git-lfs, so it diffs and greps)
  readme.2025.txt                     "Good" always on the right, key 'i' (PROTOCOL)
  Race_IAT_public_2002-2025_codebook.xlsx
                                      every year's variables with their start and end dates: block 5 cut from
                                      40 to 28 trials after 2016-09-26 "due to order effects" (PROTOCOL); the
                                      31 scales active in 2025 match the 2025 CSV's (PROTOCOL, "Verification")
  the yearly .xlsx codebooks          history; not read by any tool
